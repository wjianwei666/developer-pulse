# ⚡ AgentPulse

**Real-time AI agent ecosystem & model pricing monitor — built for developers, delivered where you work.**

AgentPulse tracks LLM pricing changes across 300+ models on OpenRouter and monitors breaking changes across 25+ critical open-source agent framework repositories. It delivers alerts via Slack, Discord, RSS, email newsletter, and a clean web dashboard.

---

## Quick Start

```bash
# Install
git clone https://github.com/wjianwei666/developer-pulse.git
cd developer-pulse
pip install -e .

# Run
python -m agentpulse.main

# Open
open http://localhost:7050
```

That's it. No API keys. No signup. AgentPulse starts monitoring immediately.

## Features

### Data Sources
| Source | Frequency | What it tracks |
|--------|-----------|---------------|
| OpenRouter | Every 6h | Pricing for 300+ LLMs (input/output/cache/vision/search) |
| GitHub Releases (25 repos) | Every 2h | Breaking changes, deprecations, migration requirements |
| MCP Registry | Every 24h | Server population census, version drift detection |

### Scoring Engine
- **Blended cost**: 7:2:1 weighted average (cache:input:output) — mirrors real agent workloads
- **Evidence-based grading**: semver jump + changelog keyword analysis → 5 tiers (breaking / likely / watch / safe / noise)
- **Prioritization**: scores clamped [0–100], events classified as alert/digest/archive

### Distribution Channels
| Channel | Format |
|---------|--------|
| **Slack** | Blocks Kit with color-coded severity |
| **Discord** | Embeds with migration steps inline |
| **RSS** | `/rss.xml` — standard RSS 2.0 |
| **Email Newsletter** | HTML + plaintext digest |
| **Web Dashboard** | `/price`, `/ecosystem`, `/search`, `/trends` |

### API Endpoints
| Endpoint | Description |
|----------|-------------|
| `GET /api/events/price` | Latest price change events |
| `GET /api/events/release` | Latest ecosystem breaking changes |
| `GET /api/events/search?q=...` | Full-text search across all events |
| `GET /api/trends/{model_id}` | Historical pricing time series |
| `GET /api/digest/{date}` | Daily digest in JSON |
| `GET /api/mcp/census` | MCP registry population stats |

## Architecture

```
OpenRouter API ──→ price_pipeline  ──→ price_events   ──→ Web / API / RSS / Slack / Discord
GitHub RSS    ──→ release_pipeline ──→ release_events ──→ /   /     /     /       /
MCP Registry  ──→ mcp_pipeline     ──→ mcp_census     ──→ daily digest (07:00 UTC)
```

- **Snapshot + diff model**: every run creates a snapshot; events are generated by comparing consecutive snapshots
- **Idempotent**: rerunning a pipeline never creates duplicate events
- **3-retry with exponential backoff**: all external fetches retry up to 3 times with 2^attempt delay
