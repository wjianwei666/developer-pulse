你前面已经有 price_watch.py + ecosystem_watch.py + build_daily.py 的原型逻辑，现在缺的是部署态定时任务。

立即做：
1. 服务器上加 cron（每 6h 采一次）：
   0 */6 * * * cd /app && python3 price_watch.py run >> /var/log/ap_price.log 2>&1
   30 */6 * * * cd /app && python3 ecosystem_watch.py run >> /var/log/ap_eco.log 2>&1
   0 1 * * * cd /app && python3 build_daily.py >> /var/log/ap_daily.log 2>&1

2. 首次运行先打基线快照（不发通知），第二次运行才出 diff。

4. 加一个 /healthz 接口 + 简单监控：快照数 0 / 数据库无写入就报警到 Discord。

验收标准：24h 内首页出现 ≥1 条 Price Event、≥1 条 Ecosystem Event、≥1 条 Digest。
